# ScepTRONIC

Consolidated Flutter app for the ScepTRONIC BLE stock-control workflow.

This copy was assembled from the current `ble_led_endurance_app` state and
includes:

- ScepTRONIC UI screens and branding assets
- iPhone Flutter UI with Bluetooth permissions
- stock controller and release LED control flows
- bundled `ver1_esp32c3_stock1` and `ver1_esp32c6_stock1` firmware folders

## Apple platform

- iPhone: use the `Runner` scheme.
- BLE discovery and LED commands require a physical iPhone.
