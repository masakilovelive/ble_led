充電検知 現状仕様
日付: 2026-03-22

1. 対象範囲
- 本書は、現在実装済みの充電検知仕様を firmware と app の両方について整理したものです。
- firmware 対象ファイル:
  - ble_led_endurance_app/ver1_esp32c6_stock1/ver1_esp32c6_stock1.ino
  - ble_led_app/ver1_esp32c6_stock1/ver1_esp32c6_stock1.ino
- app 側の充電マーク表示は、現状では ble_led_endurance_app にのみ実装されています。

2. Firmware 現状仕様
- 対象基板: XIAO ESP32-C6
- 充電検知入力: D7 = GPIO17
- 検知方式: デジタル入力のみ
- 現在の実装では、digitalRead(D7) == HIGH を充電中、LOW を非充電中として扱います。
- 電気的前提:
  - D7 は 3.3V 系のデジタル入力として使用します。
  - D7 へ 3.3V を超える電圧は入力しません。
  - 充電信号は、すでにデジタル High/Low として成立している前提です。
  - ここまでの前提では High 側はおおむね 2.5V 以上を想定していますが、しきい値余裕は大きくありません。

3. Firmware 検知タイミング
- setup() 内で D7 を 1 回読み取り、起動直後の初期充電状態として保持します。
- 起動後は常時監視します。
- Poll 間隔: 20ms
- Debounce: 120ms
- D7 が HIGH になり、debounce 時間を超えて安定した場合:
  - charging state を ON に更新
  - "[STATE] CHARGE_ON" を出力
  - front / rear LED を即時消灯
- D7 が LOW になり、debounce 時間を超えて安定した場合:
  - charging state を OFF に更新
  - "[STATE] CHARGE_OFF" を出力
  - 直前まで保持していた出力状態を再開

4. Firmware の充電中動作
- 充電中は LED を点灯しません。
- ただし以下の状態は RAM 上に保持され、充電検知で破棄しません。
  - output enable 状態
  - front color
  - rear color
  - brightness
  - rainbow / heartbeat / accel / pattern の各モード状態
- 充電中でも BLE 経由の command 受信は継続し、内部状態更新も継続します。
- ただし実際の LED 発光は charging OFF になるまで抑止します。
- charging OFF 復帰時:
  - output disabled の場合は消灯のまま
  - output enabled の場合は直前の動作モードを再開
  - solid は保持色で再表示
  - rainbow / heartbeat / accel / pattern は再開時点から動作を立ち上げ直します

5. Firmware の BLE 通知内容
- ESP32-C6 版の voltage characteristic payload は 5 byte です。
- Byte 0-1: raw ADC
- Byte 2-3: battery mV
- Byte 4: flag
- flag 定義:
  - bit0 = charging
  - 1 = 充電中
  - 0 = 非充電中

6. App 現状仕様
- 充電表示対応は ble_led_endurance_app に実装済みです。
- ble_led_endurance_app は voltage characteristic の byte4 bit0 を charging flag として解釈します。
- 受信 payload が 5 byte の binary voltage payload と判断できない場合は charging = false とみなします。
- charging state は LedUiState に UI 用の状態として保持します。
- battery voltage / percent / charging は 1 回の battery read 結果からまとめて更新します。
- charging state の更新は persist: false で扱っているため、永続設定としては保存しません。

7. App の表示仕様
- charging = true のとき、app に充電マークを表示します。
- charging = false になれば、充電マークを非表示に戻します。
- 現在、充電マーク表示に対応している ble_led_endurance_app 画面:
  - shipment inspection screen
  - stress lab screen
  - dual color screen
  - endurance screen
- app 側の役割は状態表示が中心です。
- 充電中の LED 消灯強制は app ではなく firmware 側で実施します。

8. App 実装範囲の注意
- ble_led_endurance_app:
  - charging flag 解析あり
  - 充電マーク表示あり
- ble_led_app:
  - 現在は voltage / percent のみ読取
  - charging flag の解析は未実装
  - 充電マーク表示は未実装

9. 起動時の解釈
- 充電検知は firmware 起動時点から有効です。
- setup() で初期 D7 状態を読むため、電源投入直後から charging ON / OFF の初期状態を持てます。
- 起動後の変化検知は 20ms poll + 120ms debounce で安定化しています。

10. 補足
- 本書は「現状の実装仕様」をまとめたものであり、将来案ではありません。
- D7 のデジタル検知を採用しているため、「1.0V を厳密なしきい値にする仕様」は現状実装には含まれません。
- 将来、厳密なアナログしきい値判定が必要な場合は GPIO6 ADC または外部 comparator の利用が必要です。
