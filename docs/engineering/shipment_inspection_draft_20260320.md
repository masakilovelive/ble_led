## 補足

- `accelation` は `acceleration` に修正する。
- `BLE接続確認` では接続可否だけでなく `RSSI` と接続時間も残す。
- `battery` は `読み取れた` だけでなく、電圧の実測値を保存する。
- `起動シーケンス確認` と `アプリ再起動` は、出荷判定上は `最終再接続確認` にまとめる。
- 左右ペア品の場合は `RSSI A / RSSI B` と `Battery A / Battery B` を別列で保存する。
