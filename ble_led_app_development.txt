# まとめ（固定LED / BLE / Android / Python / ESP32‑C3 / MG24）

## 1. 目的
- **MG24 / ESP32‑C3 を使った LED 制御（D9/D10, 8/16 LEDs）**
- **BLE で色/エフェクト操作（Rainbow, Accel, Heartbeat 等）**
- **誤点灯対策**
- **Android/Flutter アプリ + Python GUI で制御/検査**
- **ESP32‑C3 の自動書き込み・検査アプリ化**

---

## 2. MG24 側まとめ
- `ski_app` 系で LED 出力、BLE GATT 制御。
- `LSM6DS3` 周りはライブラリ問題 → Seeed版で通る。
- 誤点灯対策：  
  - **最初のLEDのみ誤点灯** → `serial_led_test.ino` のタイミング調整と `GRB` 順で改善。  
- D9=8 LEDs / D10=16 LEDs指定。

---

## 3. Python GUI（BLE制御系）
- `gui_ble_D9_D10.py` で MG24制御。
- `stock1_stock2.py` で MG24 2台同時制御（A/B）。
- 誤点灯対策、虹色/加速度/heartbeatを段階的に実装。
- Battery表示は後で修正。

---

## 4. Android/Flutter アプリ
- `ble_led_app` をFlutterで構築。
- **白背景→黒背景へ更新**  
- Stock1/Stock2表示を後に **A/B表記へ変更**
- `Connection Both`/`Disconnected` ボタン、タブ非表示制御など調整。

---

## 5. ESP32‑C3 対応
- C3版コード `xiao_esp32c3_stock1.ino` / `stock2` を作成。
- GPIO指定：  
  - D9→GPIO9, D10→GPIO10  
  - 後に変更：Front=GPIO5, Rear=GPIO6  
  - Battery pin=GPIO3
- Battery仕様  
  - LiFePO4: 最大3.8V / 最小2.5V  
  - LiPo: 最大4.2V / 最小3.2V
- IMUは使用しない。

---

## 6. ESP32‑C3 状態遷移チェックツール
**`gui_c3_state_check_dual.py`**
- 2台 (A/B) を同時監視
- 状態遷移をタブで可視化  
  - Advertising / Connect / GATT / Disconnect  
- **Auto After Connect / Auto Test / Manual**
- **自動ポート検知**
- **Name Collision 判定（OK=青, COLLISION=赤）**
- **ログ保存 + CSV出力**
- **登録リスト N=10000, 25件/ページ**
  - A/BのDevice Name / Port / MACを保存

### 追加済み機能
- **バッテリー値をGATT図の枠内に表示**
- **Reconnect Both Test**  
  → 接続→切断→電源OFF/ON→再接続確認  
- **Clear Memory**  
  → 登録COM/名前/MAC/チェック状態リセット  
- **AUTO TEST時にLOG連動の可視化**

---

## 7. Arduino CLI 自動書き込み
- `arduino-cli` を公式サイトから取得
- 自動書き込みの流れ：
  - COM検出 → DEVICE_NAME 書き換え → Build → Flash
- DEVICE NAME ASSIGNMENT ルール：
  - **A=奇数(2n−1), B=偶数(2n)**  
  - 例：n=2 → A=3, B=4
- Device名は  
  - `XIAO-ESP32C3-LED-<number>`
- Flashログ、Buildログ、A/B COMログを保存。
