# ScepTRONIC Build 15 App Store screenshots

ユーザー提供のBuild 15実機画面を、画面内容を切り取らず、縦横比を維持してApp Store用サイズへ変換した提出候補です。余る領域は黒で補完しています。

## 画面

- `01-stock-select-build15.png`: STOCK SELECT（A/B CONNECTED、Battery A 82%・B 75%、A Rainbow・B単色）
- `02-stock-a-setting-build15.png`: STOCK A SETTING

## サイズ

| フォルダー | 解像度 |
| --- | --- |
| `6.9-inch` | 1320 × 2868 |
| `6.3-inch` | 1206 × 2622 |
| `6.1-inch` | 1170 × 2532 |
| `5.5-inch` | 1242 × 2208 |

`basic-set`には受領したJPEG原本と、Flutterのスクリーンショット専用モードから取得した接続済みSTOCK SELECT画像を保存しています。サイズ別フォルダーの提出画像は実体もPNG形式です。

## 注意

- iPhone専用アプリ用の画像です。iPad用画像は含みません。
- App Store Connectでは、必要な表示サイズ枠へ同じフォルダー内の2枚を順番に登録してください。
- ステータスバーの時刻やバッテリー残量を含め、受領画像の画面内容は変更していません。
